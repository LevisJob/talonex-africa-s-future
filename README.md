# Talonex: Africa's Future

Single-page dark-mode homepage for "Talonex," Africa's first green hyperscale data centre (Kenya). Front-end only, no auth/DB.

Style: graphite-black bg (#0C0B09), amber accent (#FF8A3D) for CTAs, cyan accent (#4FD8C4) only for data/status. Manrope headlines (700), IBM Plex Sans body, IBM Plex Mono for stats/ticker. No rounded SaaS cards, no ALL-CAPS eyebrows, no arrow-glyph links.

Sections: (1) Sticky nav — TALONEX wordmark, nav links, amber-outline "Investment Enquiry" button. (2) Full-bleed hero — Africa continent outline graphic behind text (right side, gradient scrim left), pulsing Kenya node with 2 faint radiating lines, headline "Africa's first green hyperscale data centre," sub-line, 2 CTAs (filled amber "Explore the Facility" / outline "Investment Enquiry"), small mono status line above headline w/ pulsing dot. Stagger-fade entrance + map draws in on load. (3) Auto-scrolling stat ticker, pauses on hover: 50MW+ capacity, 90% renewable, 5 subsea cables, 99.999% uptime, USD 250M+ investment, Tier III+ rating. (4) 3-column pillars (hairline borders, line icons): Green Power / Hyperscale Ready / Africa-First. (5) About pull-quote, amber left border, "Read the full story" link. (6) 5 placeholder partner-logo chips, grid, grey→white on hover. (7) 3 news cards (tag+dot, headline, blurb, date). (8) Closing CTA banner, ambient amber glow drift behind heading, 2 CTAs. (9) Footer: prototype disclaimer + small fixed "Design prototype" badge.

Motion: only hero entrance, ticker scroll, banner glow are ambient; everything else hover-only. Fully responsive.
